# 资料范围、溯源口径与免责声明

> 本文档说明 **初版构建版（`v0.1.0-build`）** 的文献来源清册、模块完整度边界、已知缺漏以及著作权与临床免责约定。

## 1. 文献底本清册与索引文件

仓库随附的原始文本、PDF 与整理稿件统一登记于以下索引文件，且受自动测试与校验脚本核验：

- [books/README.md](../books/README.md)：记录 `books/ni-haixia-medicine/` 下 `17` 册原书的文件名、字节数与 SHA-256 摘要。
- [docs/SOURCE_REGISTRY.md](SOURCE_REGISTRY.md)：由 `python -m etl.source_inventory` 生成，汇总原书及结构化快照的 `source_id`、文本层类型与路径。
- [docs/formula-dosage-index.md](formula-dosage-index.md)：经方剂量与条文校核状态导出索引。

## 2. 模块实况与已知边界

本项目坚持**不以 AI 凭空捏造或补充底本中不存在的条文**，因此各模块明确标注实况与缺漏：

1. **黄帝内经《素问》（部分收录）**
   - 视频同步文稿上下册共 `306` PDF 页（`301` 印制页），实录 `72` 篇独特《素问》篇号（目录 `74` 条、`283` 节）。
   - **缺失篇目**：《素问》第 `51` 篇《刺禁论》、第 `66–71` 篇与第 `74` 篇（运气七大论）及第 `73` 篇《本病论（遗篇）》，共 `9` 篇在底本中未收录；全书亦**未包含《灵枢》**。
   - **校勘深度**：`24` 篇核心基石与临床辨证支柱已完成精校并关联概念，其余 `50` 篇当前保持目录与页码锚定（`pending`）。
2. **神农本草经（385 味全书复原）**
   - 前言虽沿称孙星衍辑本「三百六十五种」，实卷正经共编排 `357` 味（其中原书第 249 条误印作「二四丸、大豆黄卷」），加上第三章倪师增补仲景常用药 `28` 味，全版合计 `385` 味。
   - 相对早期 `351` 味快照补回遗漏的 `6` 味正经与 `28` 味增补药；第 2–3 PDF 页原书为空白。
3. **伤寒金匮经方（299 首）**
   - 《伤寒论》`113` 首 + 《金匮要略》`186` 首，共 `299` 首。部分条目仍按底本标注 `variant`、`manual`、`missing` 或 `unchecked` 等状态，用于提示读者交叉查阅原书页码。
4. **藏书阁（17 册）**
   - `15` 册具备可提取电子文本层或对应文稿快照，建有全库字词与目录检索（`3,303` 检索单元 / `2,777` 文本单元）。
   - 《明清名医全书大成·徐灵胎医学全书》（`434` 页）与《黄帝外经》（`85` 页）共 `2` 册为纯图像扫描 PDF，当前暂未接入 OCR 全文检索，仅提供按页浏览扫描图与目录定位。
