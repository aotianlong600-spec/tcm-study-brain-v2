# 重复方审查

## 结论

- 全库现有 299 条书目记录，按规范化方名去重后为 257 个唯一方名。
- 《伤寒论》内部没有同名条目，也没有“药味与剂量完全相同”的重复记录。
- 《伤寒论》与《金匮要略》之间有 42 个跨书同名方。它们不按重复记录删除，保留各自原文、剂量、煎法和篇章证据。
- 42 组中有 15 组当前基础数据的药味与剂量相同，另 27 组的处理字段或剂量写法不完全一致，必须逐组看原书，不能仅凭字符串自动合并。
- 伤寒内部另有 6 组“药味集合相同、但剂量、比例或剂型不同”的方，属于不同方证，不能合并。

## 伤寒内部同药味集合

- 桂枝汤 / 桂枝加桂汤 / 桂枝加芍药汤
- 桂枝去芍药加附子汤 / 桂枝附子汤
- 桂枝麻黄各半汤 / 桂枝二麻黄一汤
- 四逆汤 / 通脉四逆汤
- 抵当汤 / 抵当丸
- 半夏泻心汤 / 甘草泻心汤

以上方剂在药味、剂量比例、炮制或剂型上不同，当前作为独立方保留。

## 跨书处理规则

1. 先确认是否为同一方名、同一组成和同一剂量。
2. 若只在炮制、异体字或提取粒度上不同，保留两条书目证据，增加“同方关系”。
3. 若剂量、组成或用法确有差异，明确列版本差异，不静默合并。
4. 搜索和计数默认仍以书目记录为准，同时提供唯一方名统计，避免把 299 条误称为 299 个唯一方。

可用 `python scripts\audit_duplicate_formulas.py` 重跑审查。
