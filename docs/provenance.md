# 方剂模块数据口径

## 当前范围

这是新仓库的第一块可运行模块，只接入了：

- 《伤寒论辑义》抽取的 112 首伤寒方（另列 1 首原文明确缺失的土瓜根方）。
- 《倪海厦注神农本草经》抽取的 351 味药。

针灸、辨证论治和病症模块尚未接入，页面明确显示“待接入”，不以第三方数据占位。

## 方剂校验

`etl/extract_shanghan.py` 只在以下条件同时成立时接收一条方剂：

1. 原文中存在以“方”结尾的方名行。
2. 后续能找到“上X味”或“右X味”计数锚点。
3. 解析出的药味数与这个锚点一致。

当前 112 首中，110 首通过自动味数校验；猪胆汁方和烧裈散按同段原文补入，并单独备注来源边界。每首同时保存：

- 原文行号；
- 原文组成片段；
- 煎服法；
- 规范化药名与剂量；
- 有版本差异时的同页校注。

## 已知边界

- 大青龙汤的石膏使用“如鸡子大”而不是数字剂量，已原样保留。
- 桂枝加葛根汤、大柴胡汤、甘草泻心汤和当归四逆加吴茱萸生姜汤存在正文与校注的版本差异；页面保留正文组成和整理组成两套视图，不能把两套版本混为一条。
- 本经条目链接依赖 `etl/herb_alias.py` 的古名映射；无法确认的方中药味显示为未链接，不强行归并。
- 当前只完成了伤寒方，金匮方尚未并入正式目录。
