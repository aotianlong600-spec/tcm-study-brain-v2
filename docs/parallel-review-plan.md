# 并行逐方校对计划

## 交付原则

- 每批最多 7 首，按原书顺序。
- 智能体只写 `data/curated_batches/<批次>.json` 和对应测试，不直接改主目录。
- 主线程负责独立复核、签收、合并、生成、全量测试、页面验收和进度文档。
- 子 agent 的自测只能算提交自检，不能代替主线程或独立验收 agent 的结论。
- 批次失败或超时，原文件保留为检查点，同一路径重试，不重复改其它批次。
- 只有写入 `data/curated_batch_manifest.json` 的批次才进入正式生成数据。

## 验收闸门

`python scripts\validate_curated_batches.py` 必须返回零错误。然后执行：

```powershell
python -m etl.enrich_evidence
python -m etl.build_formula_modules
python -m unittest discover -s tests -v
python scripts\audit_formula.py
```

人工抽样还要核对：原书页是否有整段原文、剂量是否与扫描页一致、古文与现代说明是否分开、缺方和版本差异是否明示、毒剧药风险是否显眼。
